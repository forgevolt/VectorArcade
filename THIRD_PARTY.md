## FabGL

[FabGL](https://github.com/fdivitto/FabGL) by Fabrizio Di Vittorio does all the drawing:
the ST7789 driver, the double-buffered canvas and the fonts. It is licensed under
**GPL-3.0**.

The firmware cannot be built without linking FabGL, so a **built firmware image is a
combined work governed by GPL-3.0**, even though the firmware's own files are MIT.
Unlike the LGPL (see Streaming below), the GPL has no relinking exception that would let the
binary keep a more permissive licence. In practice:

| | |
| --- | --- |
| The firmware source in this repository | MIT. FabGL itself is not redistributed here, only named as a dependency. |
| A built `.bin`, or a console with the firmware on it | Conveyed under GPL-3.0. The corresponding source is this public repository together with FabGL's own. |
| Reusing files from this repository elsewhere | MIT, unaffected - as long as FabGL is not part of what is carried across. |

`software/tools/img2bitmap.py` is FabGL's image converter (`tools/img2bitmap/` in the
FabGL repository), included unmodified. It is part of FabGL and therefore GPL-3.0, not MIT;
it is a separate tool that runs on the PC, so it does not become part of the firmware.

FabGL's own notices stay intact, and nothing in this repository describes FabGL as MIT.

## Streaming

`Streaming.h` by Mikal Hart is used for logging throughout the firmware. The LGPL does not
affect the licence of this project, but it asks that anyone who receives a binary can relink
it against a modified version of the library. Complete source is published here, so a
recipient can modify Streaming and rebuild.

under the [Pixabay Content License](https://pixabay.com/service/license-summary/). It allows
use and modification, commercially too, without attribution; it does not allow selling or
distributing a clip on its own. Here each one is part of the game, and all of them were
trimmed, looped and re-encoded for it.

| Clip | Source |
| --- | --- |
| `RocketEngine.wav` | [Looking straight into a burning rocket engine](https://pixabay.com/sound-effects/film-special-effects-sfx-looking-straight-into-a-burning-rocket-engine-sound-effect-283448/) |

## Splash screens

The Asteroids splash screens (`software/VectorArcade/boards/*/AsteroidsSplash.h`) are
AI-generated artwork made for this project, with the game's own vector ship drawn into
them. They are covered by the MIT licence of this repository.

## Names

Lunar Lander and Asteroids are names of arcade games released by Atari in 1979; Tintin and
his moon rocket are creations of Hergé. VectorArcade is an independent project, not
affiliated with or endorsed by either rights holder. The games are reimplemented from their
published gameplay, and the TintinRocketShooter's housing is an original design based on the
rocket from the comics.
